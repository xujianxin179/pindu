# 06 - 图纸生成与导出

**What to build:** 生成 Build Sheet，含带辅助线的图案预览（每 5 格一条粗辅助线 + 每格细网格线 + 可选行列标号）和用色清单（色号 + 样块 + 数量），可导出为 PNG 和 PDF。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 图纸含图案预览：每格按色号着色，每 5 格一条粗辅助线，每格细网格线
- [ ] 可选叠加行列标号（1,2,3… / A,B,C…）
- [ ] 图纸含用色清单（色号 + 颜色样块 + 数量）
- [ ] 可导出为 PNG
- [ ] 可导出为 PDF（可打印）
